# Quero Passagem API

Backend for Quero Passagem, built with Laravel 13.

## Requirements

- PHP 8.4+ and Composer
- Node.js and npm
- SQLite (default database)

## Setup

```bash
composer setup
```

Installs dependencies, creates `.env`, generates the application key, runs migrations, and builds frontend assets. Edit `.env` to customize local configuration.

## Development

```bash
composer dev
```

## Tests

```bash
composer test
```
